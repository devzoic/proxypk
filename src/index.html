4G LTE Wingle Multi-Device Subnet Manager
Assign distinct subnets (192.168.8.1, 192.168.9.1, 192.168.10.1...) to use multiple wingles on one PC
Why do multiple 4G Wingles show the same IP by default?
All Huawei, ZTE, and Zong 4G Wingles come from the factory with built-in DHCP server set to gateway 192.168.8.1. When plugging 2 or more dongles into the same PC, all interfaces get 192.168.8.100, causing the operating system to send all traffic through only the first dongle.
Solution: Assign each dongle its own subnet (Dongle 1: 192.168.8.1, Dongle 2: 192.168.9.1, Dongle 3: 192.168.10.1...). Once saved in the dongle, it stays permanent!
